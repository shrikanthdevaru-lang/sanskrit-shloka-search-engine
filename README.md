## 🏗️ Storage & Architecture

1. **Storage Mechanism:** 
   - Primary 5,000 shlokas corpus bundled in `shlokas.js` (4.1 MB, ~700 KB gzipped over CDN).
   - Embedded resilient fallback of 174 core verses inside `index.html`.
2. **Execution:** 
   - Zero-database, client-side in-memory index in the browser's JavaScript V8 engine.
   - Searches take ~2 to 5 milliseconds across all 5,000 records.
3. **UI Rendering:** 
   - Smooth 30-card chunking with a *"Load More"* button prevents any DOM bloat or browser freezing.
4. **Hosting:** 
   - 100% free serverless deployment on GitHub Pages with global Fastly edge caching.

## 🤖 Vedanta AI Agent

Click the floating **🕉️ AI** button in the bottom-right corner to interact with the conversational assistant:
- **Emotional Guidance**: Express feeling sad, anxious, or unmotivated for tailored shlokas with compassionate explanations.
- **Philosophical Explanations**: Ask *"What is Karma?"*, *"Explain Dharma"*, or *"What is Brahman?"* for structured summaries with scriptural citations.
- **Scripture Overviews**: Inquire about the Bhagavad Gita, Upanishads, Vedas, Ramayana, or Chanakya Niti.
- **Direct Search Links**: Click *"View in Search"* to immediately filter the 5,000 shlokas corpus.
